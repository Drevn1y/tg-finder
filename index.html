✦ Мини-инструмент для Telegram

Открой Telegram-профиль

Введи username, ссылку t.me или номер телефона. Для местного номера Узбекистана код +998 добавится автоматически. Для других стран укажи код страны — например, 1 для США.

Примеры: username · @username · https://t.me/username · 901234567 · +1 202 555 0123

🔒
Твои данные остаются у тебя.
Ввод обрабатывается прямо в браузере. Для номера Telegram может не показать аккаунт, если владелец запретил находить себя по номеру. Это ограничение приватности Telegram, обойти его нельзя.

# TG Finder

> Лёгкая Telegram-inspired веб-визитка для быстрого открытия публичных Telegram-профилей по username или ссылке.

**Live demo:** https://drevn1y.github.io/tg-finder/  
**Repository:** https://github.com/Drevn1y/tg-finder

## О проекте

TG Finder — небольшой бесплатный статический веб-инструмент. Пользователь вводит публичный Telegram username (например, `@username`), ссылку формата `https://t.me/username` или номер телефона в международном формате (например, `+998901234567`), а приложение проверяет формат и формирует ссылку для открытия в Telegram.

Проект задуман как простая контактная визитка: без аккаунтов, серверной части, базы данных и сложной настройки инфраструктуры.

## Возможности

- Telegram-inspired интерфейс: голубая шапка, чат-пузырь, светлая палитра и адаптация под мобильные устройства.
- Принимает публичные username с символами латиницы, цифрами и подчёркиванием.
- Поддерживает ссылки `t.me` и `https://t.me/`.
- Формирует ссылку `https://t.me/username` для публичного username.
- Для номера телефона формирует ссылку `https://t.me/+<номер-без-плюса>`.
- Проверяет формат username на стороне браузера.
- Не требует регистрации и не использует backend.
- Подходит для бесплатного размещения на GitHub Pages.

## Важное ограничение

TG Finder **не выполняет самостоятельный поиск аккаунтов по номеру телефона**. Для номера он только формирует ссылку вида `https://t.me/+998901234567` (в ссылке номер передаётся без исходного плюса). Telegram может открыть чат или профиль, только если его правила и настройки приватности позволяют найти пользователя по этому номеру. Поэтому ссылка не гарантирует, что аккаунт будет найден. Сервис не перебирает номера, не собирает адресные книги и не обходит ограничения приватности.

Сформированная ссылка также не подтверждает, что профиль существует или принадлежит конкретному человеку.

## Запуск локально

1. Склонируй репозиторий:
   ```bash
   git clone https://github.com/Drevn1y/tg-finder.git
   ```
2. Открой папку проекта.
3. Запусти `index.html` в браузере.

## Публикация на GitHub Pages

1. Открой **Settings → Pages** в репозитории.
2. В разделе **Build and deployment** выбери **Deploy from a branch**.
3. Укажи ветку `main` и папку `/(root)).
4. Нажми **Save** и дождись завершения публикации.

После публикации сайт будет доступен по адресу:

https://drevn1y.github.io/tg-finder/

## Приватность

Введённое значение обрабатывается локально в браузере. Приложение не отправляет его на собственный сервер, поскольку серверная часть отсутствует. При переходе по сформированной ссылке браузер открывает Telegram; обработка номера после перехода зависит от самого Telegram и его настроек приватности.
